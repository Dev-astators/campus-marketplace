## **Meeting 2: Client Meeting (Aimee)**

**Date:** 8 April 2026  
 **Platform:** Discord  
 **Attendees:** Team \+ Client (Aimee)

### **Agenda**

* Clarify project expectations  
* Confirm development approach  
* Understand assessment requirements

### **Discussion**

* The client confirmed that not all meetings need to include her, but **proof of meetings is required for marks**  
* Emphasis was placed on:  
  * Completing documentation early as it is “easy marks”  
  * Ensuring basic software implementation is functional  
  * Clearly stating the technology stack in documentation  
* The team was advised to:  
  * Deploy the application early (e.g., Azure)  
  * Set up CI/CD from the beginning  
  * Use testing tools such as **Jest and CodeCov**  
* For Sprint 1:  
  * Focus should be on **User Acceptance Tests (UATs)**  
  * High code coverage (e.g., 80%) is a long-term goal

### **Decisions Made**

* At least 2 meetings will involve the client  
* Documentation will be prioritised alongside development  
* CI/CD and deployment will be considered early
